### The agent skill is one short file

`skills/deictic/` is a single `SKILL.md`, the loop and its rules, with no `references/`. What they explained, the
commands now say as they run: `deictic task` says how to read a task's source chain, the markup pointed at, and a task
about the page as a whole, and `deictic voice` says how to line speech up with the recording's frames.
